## 💻 Tech Stack
This is a lightweight, fast-loading, **static website**. It was built using:
*   **HTML5** (Structure)
*   **CSS3** (Styling, Flexbox, Grid, and Gradient Masks for image blending)
*   **No backend required** - The booking form has been replaced with a direct WhatsApp link for instant client communication.

1. Clone this repository:

2. Open `index.html` in any web browser to view it locally.
3. Edit `index.html` or `style.css` in your favorite code editor (like VS Code) to make changes.
4. Push your changes to GitHub, and GitHub Pages will automatically update the live site.
